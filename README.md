# MLSC Hackspiration Website

This repository contains multiple design variations for the MLSC website built for Hackspiration.
Each branch in this repo represents a different UI/UX approach or feature experiment.
The goal is to compare, evaluate, and combine the best elements from all branches to build a final polished version.

# 🔥 Project Purpose

To explore different website layouts, components, and visual styles.

To enable easy comparison between designs for better decision making.

To merge the strongest elements from each branch into one final website.

To maintain an organized workflow for collaborative UI/UX experimentation.

# 🌱 Repository Structure

```
mlsc-hackspiration-website/
│
├── main/                        # Final integrated version
│
├── design-v1/                   # First design experiment
├── design-v2/                   # Second design experiment
├── design-v3/                   # Third design experiment
│
├── component-library/           # Reusable UI components
│
├── docs/
│   ├── comparison-notes.md      # Comparison notes between branches
│   └── ui-ideas.md              # UI ideas and selections
│
└── README.md
```

# 🌿 Branch Strategy

## 1. design-v1

First website attempt

Basic layout

Minimal components

## 2. design-v2

Improved sections

Better typography

Animations

## 3. design-v3

Advanced UI

Modern theme

Creative animations

## 4. component-library

Extracted and reusable components from all designs

Helps speed up the integration phase

## 5. main (Final Version)

You will merge the best UI pieces into this

This becomes the final website for MLSC Hackspiration

Each coord should submit their website by making a pr so that we can pull the changes and compare using git checkout

Also create a file named PROJECT_INFO_<your_name>.md in your branch.

Use your own name in the filename so that everyone’s notes stay separate and we avoid merge conflicts

## 📦 Tech Stack (Recommended)

Frontend: HTML, CSS, JavaScript

Framework: Vue / React / Plain JS (depending on your designs)

UI: Tailwind / SCSS / Custom CSS

## 🔧 How to Compare Branches

Check out a branch

git checkout design-v2


## Run the project

Note down strong components

Switch to next branch

Repeat

Log comparisons in docs/comparison-notes.md

## 🤝 Contribution Guidelines

Create a new branch for every new design idea

Keep commits small and descriptive

Add screenshots in docs/ if needed

When ready, create a PR from design branch to main

Document your design decisions
